# Python Scripting for Cybersecurity

A hands-on collection of Python scripting examples designed for cybersecurity enthusiasts, students, and professionals.

This repository is organized into **branches**, where each branch focuses on a specific Python topic or cybersecurity scripting concept. The goal is to build Python knowledge step by step while introducing techniques commonly used in security automation.

---

## Repository Structure

Each branch represents a learning module.

| Branch | Description | Status |
|---------|-------------|--------|
| `01_Hello` | Python fundamentals: variables, loops, functions, data structures, and comprehensions. | Available |
| `02_Advanced_P1` | File handling, exception handling, modules, CLI applications, and virtual environments. | Available |
| `02_Advanced_P2` | Continuation of advanced Python topics. | Available |
| Future Branches | Networking, Web Requests, Multithreading, Scapy, Automation, and more. | 🚧 Coming Soon |

## Getting Started

Clone the repository:

```bash
git clone https://github.com/<your-username>/Python-Scripting-for-Cybersecurity.git
```

Move into the project:

```bash
cd Python-Scripting-for-Cybersecurity
```

Switch to a branch you'd like to explore:

```bash
git checkout 01_Hello
```

or

```bash
git checkout 02_Advanced_P1
```

---

## Requirements

- Python 3.10+
- Git

Some branches may require additional packages. If needed, install them using:

```bash
pip install -r requirements.txt
```

---

## Learning Path

It is recommended to study the branches in the following order:

1. `01_Hello`
2. `02_Advanced_P1`
3. `02_Advanced_P2`
4. Future branches as they are released
